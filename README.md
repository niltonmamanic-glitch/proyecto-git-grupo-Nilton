Descripción

 Tienda digital desarrollada con HTML, CSS y JavaScript. Su objetivo es mostrar productos de manera organizada y permitir que los usuarios interactúen con la página web.

Este proyecto permite practicar el trabajo colaborativo mediante ramas, commits y Pull Requests en Git y GitHub.

Tecnologías

- HTML5: estructura de la página web.
- CSS3: diseño visual, colores y estilos.
- JavaScript: funcionalidades interactivas.
- Git: control de versiones.
- GitHub: administración del repositorio y colaboración.

Funcionalidades

1. Búsqueda de productos.
2. Filtros de productos por categoría.
3. Carrito de compras con contador.
4. Formulario de contacto con validación.
5. Menú de navegación y secciones informativas.

Estructura del proyecto

- "index.html" – Página principal.
- "style.css" – Diseño de la página.
- "script.js" – Funcionalidades interactivas.
- "README.md" – Documentación del proyecto.

Trabajo con Git y GitHub

Se utilizaron tres ramas de trabajo:

- "integrante-A"
- "integrante-B"
- "integrante-C"

Cada rama permite desarrollar una parte del proyecto y solicitar su integración a la rama principal mediante Pull Requests.

Ejecución

Para visualizar el proyecto, descargar sus archivos y abrir "index.html" en un navegador web, manteniendo todos los archivos en la misma carpeta.
